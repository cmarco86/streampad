▶ StreamPad

Locale · iPad / iPhone

La tua videoteca, in un posto solo

Funziona senza un server applicativo. I dati e le impostazioni restano nel browser. La rete serve solo per consultare cataloghi esterni e riprodurre flussi autorizzati.

Catalogo dimostrativo

Ricerca globale

Interroga la demo e tutte le sorgenti JSON attive. Le sorgenti devono autorizzare richieste browser (CORS).

Gestione sorgenti

Puoi aggiungere cataloghi JSON pubblici o autorizzati e playlist M3U personali. Un semplice URL di un sito web non equivale a un catalogo interrogabile: la web app non aggira CORS, login o protezioni.

Aggiungi sorgente

Per API ricerca: https://esempio.it/search?q={query}. JSON accettato: array oppure {"items":[...]}, con title e url (o streams[]). Non inserire token privati nell'URL.

Sorgenti configurate

Importa catalogo locale

Carica un file JSON o M3U da File su iPad. Il catalogo viene salvato localmente e resta consultabile anche senza server.

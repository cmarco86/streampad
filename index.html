Cerca nei cataloghi

Il connettore demo analizza HTML simulato; i cataloghi JSON importati sono interrogati localmente.

Sorgenti

Il catalogo dimostrativo è sempre attivo. Puoi importare cataloghi JSON autorizzati, senza server.

Formato: array di oggetti con title, description, streamUrl, type (hls/mp4), oppure {items:[...]}. Le sorgenti vengono salvate localmente su questo dispositivo.

Connettore per sito esterno

Un sito può essere interrogato da Safari soltanto se offre un'API autorizzata e consente CORS. Un normale indirizzo web non equivale a un catalogo consultabile.

Diagnostica

Catalogo dimostrativo

Ricerca unificata

Interroga le sorgenti abilitate tramite connettori JSON, HTML o video diretto. I siti esterni devono consentire CORS. Il parser riconosce anche JSON incorporato.

Gestione sorgenti

Connettori modulari per JSON, pagine HTML pubbliche e video diretti. Per i siti HTML occorre un URL di ricerca effettivo e il permesso CORS. Nessun proxy e nessuna estrazione di video da siti terzi.

Per HTML: vengono letti dati JSON incorporati (data-page, JSON-LD, script JSON) e link delle schede (article a, .movie a, .card a). Il sito deve permettere CORS. Le schede rimandano al sito originale: non vengono estratti flussi protetti.

Sorgenti configurate

Formato JSON supportato e diagnosi

Un catalogo può essere un array di elementi o un oggetto con proprietà items. Ogni elemento deve avere title, e può contenere year, description, poster, streams (array di oggetti con url, type, label).

{"items":[{"title":"Video di prova","year":2024,"streams":[{"url":"https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8","type":"hls","label":"HLS"}]}]}

Per API di ricerca, puoi usare un URL con {query} come segnaposto. Se non è presente, l'app scarica il catalogo e filtra i titoli localmente. Errori CORS non sono correggibili da una pagina HTML ospitata su GitHub Pages.
